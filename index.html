The Story

Where Time Meets Craft

Odyssey Seiko Mods was born from a fascination with precision mechanics and the beauty of a well-built timepiece. Every watch is hand-assembled — sourcing quality movements, custom dials, cases, and bracelets, then meticulously putting them together to create something no catalogue can offer. Each build is a unique journey.

How It's Made

The Process

01
Source

Quality components sourced from trusted suppliers — movements, dials, cases, and bracelets, all selected for precision and finish.

02
Design

Each build is designed as a cohesive aesthetic — colour, texture, and proportion considered before a single component is touched.

03
Assemble

Careful hand-assembly using proper tools. Movement service, dial fitting, stem and crown installation — done with patience and precision.

04
Quality Check

Every finished watch is inspected — timekeeping accuracy, crown function, case back seal. Only when it meets standard does it leave the bench.
